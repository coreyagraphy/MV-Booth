# REA finding ledger

Method from [morluto/rea](https://github.com/morluto/rea) ("Reverse Engineer Anything"): turn the request into questions, answer each one with evidence, keep a ledger that ties each conclusion to its evidence and limits, then build your own version.

**Evidence used here:** the products' documented, observable behaviour (feature descriptions, manuals, what the processing audibly does). No binaries were decompiled. LUNA and Nectar are not installed in this build environment, and RoEx is a closed web service. For binary-level evidence, install REA on your PC (`npx rea-agents setup`) and point it at software you own. Check each product's licence first, because many EULAs restrict reverse engineering.
